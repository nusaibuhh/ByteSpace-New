# ByteSpace-New


A responsive website built for the ByteSpace New assessment, based on the provided Figma design.

- **Live Demo:** `<URL here>`

## Tech Stack

- HTML
- CSS
- Deployed on Vercel


## Project Structure

```
├── index.html            # Landing page
├── login.html            # Login page (bonus)
├── register.html         # Signup page (bonus)
├── search.html           # Search page
├── course-detail.html    # Course detail page
├── course-lessons.html   # Course lessons page
├── course-reviews.html   # Course reviews page
├── creator-profile.html  # Creator profile page
├── 404.html              # 404 Not Found page
├── styles/
   ├── style.css          # Css file
├── assets/           # Images, icons and grid background
└── README.md
```

## Getting Started

1. Clone the repository

   ```bash
   git clone <your-repo-url>
   cd <your-repo-folder>
   ```

2. Open `index.html` in your browser, or use a local server such as the VS Code Live Server extension.


## Deployment

The project is deployed on Vercel and the live link is publicly accessible.
